# Token Radar

A pre-token airdrop radar for make.fun's "Build the best token launch radar" bounty ($1,325 USDC).

**Radar-2 value model**: implied value derived entirely from the sealed DefiLlama snapshot (TVL, 7-day growth, age since listing, category/chain issuance context). Ranks 200 pre-token protocols (40 watchlist + 160 early) with protocol-specific farm plans and a static, no-framework dashboard.

Built by an AI agent for make.fun. Entry: https://make.fun/bounty/token-radar-01
